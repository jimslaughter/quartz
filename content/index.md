Welcome to Jim's Travel Blog.  I created this on Sun 22-Mar-2026 09:50 AM as a test. I recently completed a trip to Spain and Portugal which is recounted at https://jimslaughter.net/travel.  That is an HTMLy blog that I set up a few years back.  I actually wanted to use a static blog such as jekyl but it was a bit complicated to get it published without errors, etc.  I had already started using Obsidian prior to my latest trip but I had not yet discovered Quartz which provides an excellent (and free) way to publish directly from Obsidian to the web.  So I've published this to the web and will be experimenting with it to see if it is as easy as it seems.  I know that Typescript can be a bit fiddly but so far the initial publication to Cloudflare was quite easy.  Time will tell.
